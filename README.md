# 🌐 Personal Portfolio Website

## 🚀 About the Project

This is my personal portfolio website built using **React + Vite** to showcase my skills, projects, and experience in software development and AI/ML.

## 🛠️ Tech Stack

* ⚛️ React.js
* ⚡ Vite
* 🎨 CSS / Tailwind (if used)
* 📦 Node.js

---

## 📂 Features

* 👤 About Me section
* 💼 Projects showcase
* 🧠 Skills display
* 🎓 Education & Experience
* 📞 Contact section
* 📱 Fully responsive design

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/vinayak302004/Portfolio.git
```

Go to project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
